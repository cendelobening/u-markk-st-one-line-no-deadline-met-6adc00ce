A make.fun entry for the "One Line, No Deadline Met" bounty: a program that writes a single-line joke excusing a missed deadline. The line is one sentence, under 200 characters, with a fresh angle and a punch at the end — the kind of excuse someone would actually blurt out when cornered about a deadline.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — exactly one line, with no trailing newline.
